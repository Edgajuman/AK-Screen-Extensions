# Delivery Checklist

Control de entrega persistente: imagen, sonido, subtítulos, créditos, licencias y revisiones. Flota el checklist mientras revisas el programa.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/delivery-checklist.png)

Versión 1.3.0, AK Screen 2.4.0. Autor: dehuman.

Instala desde el catálogo y abre Herramientas → Delivery Checklist, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.



Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
