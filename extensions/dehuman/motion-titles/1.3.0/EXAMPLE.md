# Motion Titles

Títulos con degradados, contorno y animación por caracteres.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/motion-titles.png)

Versión 1.3.0, AK Screen 2.4.0. Autor: dehuman.

Instala desde el catálogo y abre Herramientas → Motion Titles, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Crear título
- Crear rótulo de identificación
- Crear cartela legible
- Sombra suave
- Fondo legible
- Contorno blanco

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
