# Notas de edición

Notas persistentes, sin conexión ni permisos de proyecto.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/notes.png)

Versión 1.3.1, AK Screen 2.4.0. Autor: edgajuman.

Instala desde el catálogo y abre Herramientas → Notas de edición, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.



Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
