# Finish Tools

Grano de película y limpieza de fondo.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/finish-tools.png)

Versión 1.3.0, AK Screen 2.4.0. Autor: dehuman.

Instala desde el catálogo y abre Herramientas → Finish Tools, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Grano
- Eliminar fondo
- Desenfoque suave
- Resplandor
- Movimiento de cámara
- Viñeta
- Bokeh
- Desenfoque de movimiento
- Desenfoque RGB
- Reducción de ruido
- Reducción de zumbido
- Control de sibilancias
- Limitador de picos

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
