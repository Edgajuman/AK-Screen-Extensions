# Chart Atelier

Crea comparaciones animadas con barras, líneas, anillos y gráficos circulares. Colores, duración, valores y contornos editables; todas las capas quedan en la timeline.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/chart-atelier.png)

Versión 1.3.1, AK Screen 2.4.0. Autor: edgajuman.

Instala desde el catálogo y abre Herramientas → Chart Atelier, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Crear gráfico animado

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
