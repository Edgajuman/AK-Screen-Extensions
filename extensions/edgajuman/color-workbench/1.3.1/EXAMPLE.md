# Color Workbench

Accesos de color y acabado visual no destructivo para la selección actual.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/color-workbench.png)

Versión 1.3.1, AK Screen 2.4.0. Autor: edgajuman.

Instala desde el catálogo y abre Herramientas → Color Workbench, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Lumetri
- Viñeta
- Grano de película
- Look cinematográfico
- Bokeh
- Desenfoque de foco
- Resplandor
- Eliminar fondo
- Desenfoque gaussiano
- Desenfoque por canal
- Desenfoque de movimiento
- Movimiento de cámara
- Textura de película

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
