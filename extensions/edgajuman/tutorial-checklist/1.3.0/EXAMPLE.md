# Checklist de tutorial

Preparación de tutoriales con estado persistente.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/tutorial-checklist.png)

Versión 1.3.0, AK Screen 2.4.0. Autor: dehuman.

Instala desde el catálogo y abre Herramientas → Checklist de tutorial, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.



Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
