# Motion Kit

Presets editables para capas 3D, cámara de composición, rótulos y acabados de movimiento.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/motion-kit.png)

Versión 1.3.1, AK Screen 2.4.0. Autor: edgajuman.

Instala desde el catálogo y abre Herramientas → Motion Kit, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Aplicar transformación 3D
- Plano frontal
- Activar cámara 3D
- Órbita diagonal
- Cámara 2D
- Restablecer cámara
- Crear título animado
- Movimiento de cámara
- Desenfoque de movimiento
- Resplandor

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
