# Camera Tools

Cámara compartida 2D/3D y presets.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/camera-tools.png)

Versión 1.3.1, AK Screen 2.4.0. Autor: edgajuman.

Instala desde el catálogo y abre Herramientas → Camera Tools, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Cámara 2D
- Inclinar capa
- Activar cámara 3D
- Restablecer cámara
- Órbita suave
- Vista frontal
- Ajustar profundidad y giro
- Vista superior
- Órbita inversa

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
