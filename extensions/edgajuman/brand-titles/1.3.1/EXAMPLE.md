# Brand Titles

Títulos de marca con degradados, contorno, fondo, fuente y entrada animada. Crea capas de texto editables sin descargar medios.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/brand-titles.png)

Versión 1.3.1, AK Screen 2.4.0. Autor: edgajuman.

Instala desde el catálogo y abre Herramientas → Brand Titles, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Título con degradado y entrada

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
