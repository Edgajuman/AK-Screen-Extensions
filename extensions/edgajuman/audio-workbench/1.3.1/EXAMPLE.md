# Audio Workbench

Widgets rápidos para limpiar voz, controlar dinámica y preparar música desde la selección actual.

![Vista ilustrativa](https://edgajuman.github.io/AK-Screen-Extensions/previews/audio-workbench.png)

Versión 1.3.1, AK Screen 2.4.0. Autor: edgajuman.

Instala desde el catálogo y abre Herramientas → Audio Workbench, o el panel Widgets. Los widgets permiten panel y ventana flotante según su manifiesto.

- Limpieza de diálogo
- Reducir zumbido
- Reducir ruido
- Reducir reverberación
- Eliminar clics
- Realzar voz
- Control de dinámica
- Suavizar sibilancias
- Limitar picos
- Ecualizador gráfico
- Imagen estéreo
- Espacio
- Intercambiar canales
- Duplicar canal izquierdo
- Duplicar canal derecho
- Invertir polaridad

Los cambios de versión conservan los datos locales. El usuario puede borrar los datos de forma separada al desinstalar. El CSS de los widgets usa únicamente los selectores nativos permitidos.
